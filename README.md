# Java Maven CI/CD Pipeline

## Project Overview
This project demonstrates a CI/CD pipeline for building,
testing, and deploying a Java application using Jenkins,
Maven, Docker, Git, and GitHub.

## Technologies Used
- Linux (Ubuntu)
- Git and GitHub
- Bash Scripting
- Java 17
- Maven
- Jenkins
- Docker

## CI/CD Workflow
1. Fetch source code from GitHub.
2. Build and test the Java application using Maven.
3. Build a Docker image.
4. Deploy the application in a Docker container.
5. Verify application health.

## Project Goal
To automate Java application build and deployment using
DevOps tools and practices.
